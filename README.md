## Hot Projects

- [OpenSim CLI](https://github.com/GuduleLapointe/opensim-cli) — A command-line interface for OpenSimulator, enabling the installation, configuration, and management of an OpenSim server.
- [W4OS WordPress Plugin](https://github.com/GuduleLapointe/w4os) — The same functionality as the command-line interface (CLI), provided as a WordPress plugin.

These are built upon:

- [OpenSim Helpers](https://github.com/GuduleLapointe/opensim-helpers) — Web-based tools dedicated to core system functions (search, currency management, offline messaging, etc.).
- [OpenSim Engine (API)](https://github.com/GuduleLapointe/opensim-engine) — The bridge between the OpenSimulator server and the command-line interface (CLI), auxiliary tools, W4OS plugins, or third-party applications.
- [OpenSim REST PHP](https://github.com/GuduleLapointe/opensim-rest-php) — A REST API client for accessing "Robust" and the OpenSim console.

And a few .deb packages (unmodified, simply packaged for convenience—for both you and me):

- **opensim** — A .deb package containing the latest stable version of the system, ready for installation via APT (currently `opensim-0.9.3.0`).
- **opensim-unstable** — The latest development version.
- **opensim-0.9.3.0-gloebit** — Gloebit currency dll .deb package.
- **opensim-0.9.3.0-opensimsearch** — Inworld search dll .deb package. ## And much more...
